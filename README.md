## About the course

This repository contains the learner-facing v11 courseware for producing, improving and evaluating scalable professional graphics in Adobe Illustrator. The slide deck is concept-led and highly visual; detailed procedures, evidence requirements and acceptance criteria are kept in the Learner Guide and individual lab folders.

## Learning outcomes

By the end of the course, learners will be able to:

- apply basic Illustrator techniques to create digital graphics;
- improve Illustrator graphics through controlled experimentation; and
- evaluate and adapt digital graphics against visual, technical and rights criteria.

## Topics covered

- Basic digital graphics design: vector foundations, workspace, artboards, selection, shapes, colour, strokes, layers and transforms.
- Improving graphics: construction methods, pen and brush systems, gradients, patterns, symbols, appearance and typography.
- Evaluating graphics: linked imagery, Image Trace, output formats, package/preflight, intellectual property and peer review.
